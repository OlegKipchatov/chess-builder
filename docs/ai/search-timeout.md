# Тайм-аут расчёта из PGN пользователя

PGN: 1. g4 e5 2. g5 f6 3. b3 fxg5 *. BotTargetElo 446, BotEffectiveElo 460.4859445538423, seed 219237029. Версия пользователя 0.2-v20. Экспорт содержит Stockfish timeout. Позиция корректна и история совпадает с FEN. Локальный SF19 ответил e3 за 373 мс на прежних параметрах, глубина 10. Сам тайм-аут на iPhone не воспроизведён. В старой версии одно сообщение использовалось и для 60-секундной инициализации, и для 15-секундного поиска, поэтому по этому PGN невозможно строго установить стадию сбоя.

Обнаруженный недостаток: в интерактивном humanized-поиске были только depth 10 и nodes 500000, без movetime. На медленном устройстве приложение могло уничтожить ещё работающий движок через 15 секунд, вместо получения последнего найденного варианта.

Теперь интерактивный поиск отправляет go depth 10 nodes 500000 movetime 2500. При достижении временного бюджета сам Stockfish завершает поиск и возвращает результат. Если ответ не поступает, клиент отправляет stop на 6000 мс, а на 15000 мс сохраняется аварийная остановка. Полный полученный MultiPV используется моделью сложности; при отсутствии полного пакета остаётся проверенный на легальность bestmove. Это ограничение времени поиска, не гарантия 2.5 секунд общего ответа: инициализация, планирование браузера, зависание Worker и фоновые ограничения учитываются отдельно.

Инициализация и поиск получают разные сообщения: Stockfish initialization timeout / Stockfish search timeout. Сообщение Worker больше не заменяется общим текстом, если есть конкретное. Оба таймера снимаются при завершении, ошибке и отмене; поздние ответы после уничтожения Worker игнорируются. Завершение без потери рейтинга остаётся доступным при фактическом сбое.

Офлайн-симуляции analysisOnly сохраняют фиксированные depth/nodes без wall-clock лимита, если не передан отдельный лимит анализа. Seed воспроизводим для одинакового набора кандидатов, однако разные устройства под временным ограничением могут остановиться на разной глубине и получить разные кандидаты. Старые симуляции модели не доказывают качество всех возможных ранних остановок на телефоне.

Проверки: реальный SF19 с полным PGN и точным seed; fake-clock stop до аварийного тайм-аута; успешный ответ после stop; зависший Worker; различение инициализации и поиска; отмена обоих таймеров; игнорирование позднего ответа; существующие проверки легальности и MultiPV. PWA v21.
