# Ослабление защиты крупных фигур

Вероятность замены уже выбранного опасного хода снижена с 0.85 до 0.60. Добавлена явная конфигурация guard.rescueProbability. Вес такого кандидата при первичном выборе остаётся 0.15; классификация опасных ходов, легальность, fallback и прежний множитель ошибок 1.15 сохранены. Дополнительных поисков движка нет.

Сравнение: 14 фиксированных позиций, 3000 выборов на позицию, 7 Elo, seed 20260912. Всего 588000 выборов для двух настроек. Loss измерен сохранённым независимым более глубоким анализом, включая условную mate utility. Это не измерение человеческого Elo или процента побед.

| Elo | Опасные ходы до | После | Изменение среднего loss |
|---|---:|---:|---:|
| 400 | 0.407% | 1.024% | +1.21% |
| 600 | 0.310% | 0.833% | +1.95% |
| 800 | 0.162% | 0.412% | +1.83% |
| 1000 | 0.064% | 0.169% | +1.55% |
| 1200 | 0.012% | 0.062% | +1.56% |
| 1400 | 0.007% | 0.007% | +0.02% |
| 1600 | 0.000% | 0.000% | +0.00% |

Эффект небольшой и преимущественно на низких рейтингах: защита применяется к узкому классу ходов. Сохраняется монотонность loss и качества по 7 Elo для трёх seed. Добавлен тест, подтверждающий, что ранее спасённый ход теперь допускается, а часть опасных ходов по-прежнему заменяется.

Старый тест искусственного пула из одного безопасного хода и одного зевка ферзя требовал менее 4% зевков. После намеренного ослабления этот предел устарел: установлен предел 9%, то есть более 90% ходов даже в таком пуле остаются безопасными. Проверка реальных позиций для 600–1000 Elo сохраняет прежний предел 1% опасных ходов.

Воспроизведение: node scripts/simulation/guard-softening.mjs; npm run simulate; npm test. Текущая основная симуляция сохранена в results/simulation.json. Отчёты softening.md и results/softening.json фиксируют предыдущий этап настройки. PWA-кэш v17.
