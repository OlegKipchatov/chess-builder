# UI-модули GachaChess

- Стек: нативные ES-модули, HTML-шаблоны и CSS. React и сборщик не добавлены.
- `dist/index.html`: документ и корневой контейнер.
- `dist/ui/shell.js`: однократная сборка оболочки и восьми страниц до установки обработчиков.
- `dist/ui/pages/`: композиция экранов; заголовки используют `pageHeader` со слотами.
- `dist/ui/primitives.js`: кнопки, заголовки, статистика, badge, disclosure, пустое состояние и экранирование.
- `dist/ui/components/`: оболочка, участники, управление просмотром, журнал, архив, коллекция, календарь, сундук и превью наборов.
- `dist/ui/dialog.js`: открытие, подписи закрытия, доступное название и возврат фокуса.
- `dist/ui/dialog-content.js`: шаблоны отдельных сценариев диалогов.
- `dist/ui/styles/`: токены, базовые элементы, оболочка и предметные стили.
- `dist/style.css`: только явный порядок подключения модульных стилей.
- `dist/app.js`: состояние приложения, обработчики и координация игровых сценариев.
- `dist/board.js`, `pieces.js`: существующие доска, анимация и графика; переиспользуются игрой и архивом.
- `dist/activity-model.js`, `collection-model.js`: вычисления без зависимости от представлений.
- `activity.js` и `collection.js`: совместимые точки экспорта для прежних потребителей.

## Контракты

- UI-функции возвращают HTML и не сохраняют игровой прогресс.
- Текстовые значения и атрибуты экранируются; HTML-слоты принимают только доверенную разметку компонентов.
- Существующие ID и data-атрибуты сохранены как контракты с контроллером.
- Оболочка монтируется один раз. Нельзя повторно монтировать её после привязки событий.
- Сдача остаётся слева в MatchHeader; кнопки возврата принадлежат PageHeader.
- Общая высота виртуализированной строки архива задаётся в `archive-list.js` и передаётся CSS-переменной.
- Формат localStorage, экономика, ИИ и игровые правила сохранены.
- Каждый новый JS/CSS-файл должен попасть в ASSETS service worker; тест проверяет вложенные зависимости.
