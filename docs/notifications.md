# Единые уведомления — 20 октября 2026

## Контракт

`useOverlays().toast(text, { type })`, типы `error | warning | success | neutral`.
По умолчанию neutral. Каждый вызов получает новый ID: одинаковые тексты не
объединяются. Вызывать из обработчика события/ошибки, а не из эффекта,
наблюдающего строку ошибки. `useNotificationError` сохраняет состояние ошибки
для повторной попытки и сообщает о каждом отдельном отказе.

- Сверху по центру, с safe area, над нативным dialog через manual popover.
- Ширина по содержимому, максимум 360px или ширина экрана минус 24px.
  Минимальная высота 44px; область крестика 44×44px, кольцо 30px.
- Три читаемых карточки, новые сверху. Старые уходят в затухающий стек,
  скрыты от accessibility tree и не принимают ввод. Три старые карточки образуют
  видимый хвост стопки: шаг 10px, масштаб 96/92/88%, прозрачность 75/50/25%.
  Единый абсолютный слой измеряет реальную высоту карточек; добавление и удаление
  плавно меняют transform, не переключая элементы между flow и absolute.
- У каждой пять секунд от создания; открытие/закрытие модалки, новые сообщения
  и рендеры отсчёт не перезапускают. Кольцо вокруг крестика уменьшается линейно.
- Закрытие крестиком (зона 44×44) или свайпом влево или вниз от 32px с преобладающей
  вертикальной составляющей. Вправо/вверх не закрывается; отменённый жест сбрасывается.
- Вход Enter 260ms, выход Exit 180ms, стек Standard 200ms. Reduced motion
  отключает анимации, сохраняя таймер и жесты. Нет кадрового React setState.
- Поверхности нейтральные; тип обозначается семантическим цветом текста и мягкой подложки, без иконки и обводки.
  Error объявляется через alert, остальные через status. Фокус не перехватывается.
- Тексты сбоев не создают блоков внутри страниц/диалогов. Кнопки восстановления
  остаются доступны после исчезновения уведомления. Объяснения учебных ошибок
  в шахматах, состояния загрузки, цены и причины disabled — содержимое экрана.

## Уже были уведомлениями — приведены к общему API

- PGN скопирован → success; копирование, скачивание, системная отправка → error.
- Пустой буфер → neutral; невозможность вставки → error.
- Ошибка восстановления шахматной позиции → error.
- Коллекция, сундук, календарь, операции PvE и партии: ошибки транзакций → error.
- «Резерв заполнен» и отказ расстановки фигуры → warning.
- «Фигура эволюционировала. Уровень и опыт сохранены» → success.

## На рассмотрение — пока не изменено

| Текущий текст / предлагаемая формулировка | Где | Предложение |
| --- | --- | --- |
| «Можно продолжить: бонус начислится после анализа» | Награда после партии, MatchReward | Однократное neutral при закрытии награды, если расчёт ещё идёт; сам прогресс оставить |
| «Вы смотрите прошлую позицию. Вернитесь к текущему ходу, чтобы продолжить» | Текущая партия, GamePage | Neutral при первой попытке сделать ход в просмотре; потребуется явное действие возврата, чтобы статус не потерялся |
| «Награда получена: +N монет» (новое подтверждение) | Календарь активности, получение задания/награды серии | Success после успешной записи; галочку выполнения сохранить |

Не переносить результат партии, учебные объяснения неверного хода, стоимость,
недостающие ресурсы, пустые состояния и инструкции установки PWA: это информация
для текущего решения, а не кратковременный результат операции.

## Open source

Проверены API и исходники Sonner (https://github.com/emilkowalski/sonner):
position=top-center, visibleToasts=3, duration=5000, swipeDirections=[top],
разные ID для повторов и custom/headless-карточки подходят. Круговой индикатор
потребует собственной реализации и согласования с таймерами. Существующий
manual-popover слой нужен для native dialog. В этой поставке расширен уже
имеющийся компонент: новая зависимость не добавлена.

## Проверка

Регрессии: повторные одинаковые действия, независимые дедлайны, три видимых
карточки, inert-стек, закрытие только влево/вниз, отмена жеста, крестик, отсутствие
кражи фокуса, перенос между страницей и modal без сброса времени, PGN, повторная
запись награды. Браузерный QA и переход установленной PWA требуют отдельной
проверки на устройстве: в текущей среде нет доступного control-browser.
