# Chess Vault

Устанавливаемая PWA с шахматами против компьютера или вдвоём на одном устройстве, игровыми монетами и коллекцией цветовых скинов фигур. Интерфейс на русском языке, адаптирован для телефона и компьютера.

## Запуск

Нужны Python 3 и Node.js 20+ для тестов. Зависимости устанавливать не требуется.

```sh
npm start
npm test
```

Откройте http://localhost:8080. Для установки PWA на другом устройстве нужен HTTPS. На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой».

## Возможности

- Легальные ходы, шах, мат, пат, рокировка, взятие на проходе, выбор фигуры при превращении, повторение позиции и правило 50 ходов через chess.js 1.4.0.
- Компьютер: поиск на два полухода с оценкой материала, работает в Web Worker. Это простой соперник, не Stockfish.
- Сохранение полной PGN партии, баланса и коллекции в localStorage. Продолжение после перезагрузки и офлайн после успешного кэширования приложения.
- Восемь наборов: базовый и семь выпадающих. Скины меняют палитру фигур и доски; форма фигур одинакова.
- 100 приветственных монет. Победа против компьютера — 60, ничья — 40, поражение — 25. Локальная завершённая партия — 40. Награда после 10 полуходов, при мате ограничение снимается. Перезапуск партии не даёт монеты.
- Сундук стоит 100 монет: обычный 60%, редкий 30%, эпический 9%, легендарный 1%. Внутри редкости наборы равновероятны. Дубликат возвращает 35 монет.
- После девяти открытий без эпического/легендарного набора десятое гарантирует эпический (90%) или легендарный (10%). Получение такого набора сбрасывает счётчик.
- Списание, выдача и коллекция сохраняются одним снимком до показа результата сундука. Завершённая партия помечается оплаченной до показа награды.

## Структура

- `dist/index.html`, `style.css` — интерфейс.
- `dist/app.js` — состояние приложения и обработчики действий.
- `dist/engine.js` — наборы, экономика, вероятности, компьютерный соперник.
- `dist/chess.js` — vendored chess.js 1.4.0 (BSD-2-Clause, см. CHESS-LICENSE).
- `dist/bot-worker.js` — вычисления соперника вне основного потока.
- `dist/sw.js`, `manifest.webmanifest`, иконки — установка и офлайн.
- `tests/game.test.js` — проверки правил, наград, вероятностей и соперника.

Используются нативные ES-модули, без сборки и CDN. Для выпуска обновления меняйте CACHE в sw.js. Новый service worker активируется после закрытия старых вкладок.

## Ограничения

Прогресс привязан к браузеру: без аккаунта, облачной синхронизации, сетевого мультиплеера или серверной защиты монет. Очистка данных браузера сбрасывает коллекцию. localStorage можно изменить вручную, поэтому экономика подходит для локальной игры без покупок за реальные деньги. Одновременная игра в нескольких вкладках не поддерживается; изменения другой вкладки перезагружают приложение.

PWA-ресурсы подготовлены и их ссылки проверены. Фактическая установка на iOS/Android и визуальные сценарии в браузере не проверялись автоматически.

## Публикация в GitHub Pages

Workflow `.github/workflows/pages.yml` запускает тесты и проверку PWA при push и pull request в `main`. После успешных проверок push в `main` публикует содержимое `dist` в GitHub Pages. Публикацию также можно запустить вручную в Actions → Test and publish Chess Vault → Run workflow.

Однократная настройка репозитория: Settings → Pages → Build and deployment → Source: **GitHub Actions**. Если Pages ещё не включён, этап Configure Pages завершится ошибкой до этой настройки. Секреты или персональный токен не требуются. После настройки повторите запуск workflow.

Адрес после успешной публикации: https://olegkipchatov.github.io/chess-builder/

Все ссылки и PWA scope относительные, поэтому приложение работает в подкаталоге `/chess-builder/`. GitHub Pages предоставляет HTTPS. Исходная конфигурация Sites не нужна для GitHub Pages и не включена в перенос.
