# Chess Vault

Шахматы с коллекционными фигурками, досками и собственными наборами. Русский интерфейс, установка как PWA, игра без интернета после загрузки кэша.

## Запуск и публикация

Нужны Python 3 и Node.js 20+ для тестов. Зависимости устанавливать не требуется.

```sh
npm start
npm test
```

Локальный адрес: http://localhost:8080. Размещённый сайт: https://olegkipchatov.github.io/chess-builder/

GitHub Actions проверяет правила, экономику, миграцию сохранений, PWA и синтаксис при push и pull request в `main`. Push в `main` после успешных проверок публикует `dist` в Pages. Однократно выберите Settings → Pages → Build and deployment → Source: **GitHub Actions**. Если Pages не включён, Configure Pages завершится ошибкой. Повторить публикацию можно через Actions → Test and publish Chess Vault → Run workflow.

Все ссылки и PWA scope относительные, приложение работает в `/chess-builder/`. На iPhone: Safari → «Поделиться» → «На экран Домой».

## Фигуры и наборы

- Функциональные минималистичные SVG вместо Unicode-символов: белые явно светлые, чёрные тёмные, цветовые детали обозначают стиль. Не зависят от шрифта или emoji-подстановки ОС.
- 8 стилей × 6 типов фигур = 48 скинов, плюс 8 досок. Базовые 6 фигур и доска доступны сразу; остальные 49 предметов можно выиграть или создать.
- Скин — отдельный коллекционный предмет для одного типа фигуры (например, конь «Глубина»), который применяется ко всем коням обеих сторон. Цвет стороны сохраняется.
- Для каждого из шести типов можно выбрать свой стиль. Доска выбирается независимо.
- Можно сохранить до 12 собственных сочетаний с именами. Готовая коллекция применяется, когда получены её 6 фигур и доска.
- При обновлении каждый старый набор автоматически превращается в 6 фигур и доску. Баланс монет, PGN, счётчик гарантии, статистика и флаг выплаченной награды сохраняются. Старый ключ localStorage не удаляется.

## Сундуки и две валюты

**Монеты** зарабатываются в партиях и открывают сундуки. **Осколки** приходят за дубликаты и открытия без предмета; их можно потратить на конкретный предмет в коллекции. Обмена осколков обратно на монеты нет: компенсация приближает к нужному предмету, а не создаёт цикл повторных случайных открытий.

Стартовый баланс — 100 монет, сундук — 100 монет.

| Обычное открытие | Вероятность |
| --- | ---: |
| Один скин фигуры | 85% |
| Одна доска | 10% |
| Только 15 осколков, без предмета | 5% |

Если выпадает предмет, его редкость определяется отдельно: обычный 60%, редкий 30%, эпический 9%, легендарный 1%. Внутри типа и редкости предметы равновероятны; базовые предметы не выпадают.

После девяти открытий без эпического/легендарного предмета десятое гарантирует один из них (90% эпический, 10% легендарный). На гарантии вероятность типа — фигурка 90%, доска 10%, вариант без предмета исключён. Открытие только с осколками продвигает счётчик гарантии. Эпический/легендарный дубликат тоже сбрасывает счётчик: гарантия относится к редкости, а не новизне. Создание предмета за осколки на счётчик не влияет.

| Редкость | Повтор фигурки | Создание фигурки | Повтор доски | Создание доски |
| --- | ---: | ---: | ---: | ---: |
| Обычная | 8 | 40 | 16 | 80 |
| Редкая | 20 | 100 | 40 | 200 |
| Эпическая | 60 | 300 | 120 | 600 |
| Легендарная | 150 | 750 | 300 | 1500 |

Все значения в осколках. Пять повторов одного уровня и типа дают достаточно осколков для выбора нового предмета того же уровня. Создание требует подтверждения цены. Повторное создание уже полученного предмета запрещено.

Списание, компенсация и инвентарь сохраняются одним снимком до показа результата. При ошибке записи покупка не применяется. Сохранение v2 использует `chess-vault-v2`; первоначальная миграция читает `chess-vault-v1`.

## Шахматы

Легальные ходы, шах, мат, пат, рокировка, взятие на проходе, выбор фигуры при превращении, повторение позиции и правило 50 ходов через chess.js 1.4.0. Перемещение анимируется за 240 мс; взятый предмет исчезает, при рокировке двигаются король и ладья. Настройка ОС «уменьшить движение» отключает эти анимации. На доске доступны управление стрелками и выбор через Enter/пробел.

Компьютер работает в Web Worker, не блокирует интерфейс:

- **Новичок**: один полуход и шум в оценке, допускающий ошибки.
- **Обычный**: до двух полуходов, оценка материала, развития пешек и положения лёгких фигур.
- **Сложный**: итеративное углубление до четырёх полуходов, alpha-beta, до 1,8 секунды и 16 000 узлов на ход. Использует результат последней завершённой итерации.

Это простой локальный движок, не Stockfish; уровень не привязан к Elo. Сложность можно менять между ходами, она сохраняется. Автоматической адаптации к игроку нет.

Победа против компьютера — 60 монет, ничья — 40, поражение — 25. Вдвоём на устройстве завершённая партия — 40. Награда после 10 полуходов, при мате ограничение снимается. Перезапуск без завершения не даёт награды. Сложность не меняет выплаты.

## Структура

- `dist/app.js` — координация приложения, действия и сохранение транзакций.
- `dist/catalog.js` — предметы, стили, цены и компенсации.
- `dist/economy.js` — вероятности, открытие сундуков и создание предметов.
- `dist/state.js` — модель состояния, проверка экипировки, миграция v1 → v2.
- `dist/collection.js` — каталог, готовые коллекции, сохранённые наборы.
- `dist/pieces.js`, `dist/board.js` — SVG-фигуры, доска и анимации.
- `dist/engine.js`, `dist/bot-worker.js` — сложность и шахматный соперник.
- `dist/chess.js` — vendored chess.js 1.4.0 (BSD-2-Clause; см. CHESS-LICENSE).
- `dist/sw.js`, `manifest.webmanifest`, иконки — установка и офлайн.
- `tests` — правила, анимационные маршруты, экономика, миграция и PWA.

Нативные ES-модули, без сборки и CDN. В версии 2 HTML и ссылки модулей используют `?v=2`, чтобы старый service worker не подставил несовместимые модули при первом обновлении. Service worker кэширует согласованную оболочку. При новом выпуске обновляйте CACHE и версию ссылок вместе. Для применения ожидающего обновления есть кнопка; также можно закрыть все вкладки приложения и открыть его снова. Прогресс сохранится.

## Ограничения и проверки

Прогресс хранится в браузере: без аккаунта, облачной синхронизации, сетевого мультиплеера и серверной защиты монет. Очистка данных браузера сбрасывает коллекцию. Одновременная игра в нескольких вкладках не поддерживается; изменение снимка в другой вкладке вызывает перезагрузку.

Вероятности, создание предметов, дубликаты, миграция, шахматные правила и соперник покрыты автоматическими тестами. Проверка анимационных маршрутов не заменяет визуальную проверку на реальном устройстве. Установка PWA на iOS/Android отдельно не проверялась.
